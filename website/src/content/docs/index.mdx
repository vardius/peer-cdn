## What you get

<CardGrid>
	<Card title="Routes in your worker" icon="setting">
		Send requests for a path through middleware, asked in order or all at once: the cache, the other
		visitors, the network, or your own.
	</Card>
	<Card title="Visitors share their cache" icon="random">
		Each open page shares what its worker cached, and finds files among the other visitors for its worker,
		over [peer-data](https://vardius.github.io/peer-data/) data channels.
	</Card>
	<Card title="Careful with what it shares" icon="approve-check">
		Only same-origin 200 responses not marked `private` or `no-store`. Scripts and stylesheets come from a peer
		only when they match the request's Subresource Integrity metadata.
	</Card>
	<Card title="The network as a fallback" icon="rocket">
		What no cache or visitor has comes from your server. Requests you don't route are left to the browser.
	</Card>
	<Card title="Vite plugin" icon="puzzle">
		`peer-cdn/vite` bundles your worker into one script for every browser, and runs the signaling server on
		Vite's own server while you develop.
	</Card>
	<Card title="Small and typed" icon="star">
		ES modules in strict TypeScript. The worker side has no dependencies; WebRTC stays in the pages.
	</Card>
</CardGrid>

## Coming from v1

<div class="landing-lead">
	The router, the strategies and the plugins keep their shape. Import them instead of loading a global, bundle
	the worker, and let PeerPlugin answer the worker by itself.
</div>

<div class="compare">

```js title="v1"
self.importScripts('/peer-cdn/index.js');
const { CachePlugin, NetworkPlugin } = PeerCDN;
const { ordered } = PeerCDN.strategies;

const cachePlugin = new CachePlugin({ version: 1 });
const networkPlugin = new NetworkPlugin();

const cdn = new PeerCDN();
cdn.GET('/css/main.css', ordered,
  cachePlugin.getMiddleware,
  networkPlugin.getMiddleware);
cdn.register();
```

```ts title="v2"
import { CachePlugin, NetworkPlugin, PeerCDN, ordered } from 'peer-cdn';

const cache = new CachePlugin();
const network = new NetworkPlugin();

new PeerCDN()
  .GET('/css', ordered,
    cache.getMiddleware,
    network.getMiddleware)
  .register();
```
