The [examples folder](https://github.com/vardius/peer-cdn/tree/master/examples) holds a small site with six
pictures. Serve it from a clone of the repository:

```sh
npm ci
npm run examples
```

Open http://localhost:5173 in one browser, then in a second browser, or a private window, while the first stays
open. The second gets the pictures from the first over WebRTC, and the count of pictures the server sent stays
the same. Tabs of one browser share its cache, so they never need a peer.

## Two visitors in one page

`examples/visitors/visitor.ts` is a visitor without a service worker, which the [live demo](../demo/) runs twice
in one page. Its tests run it in Chromium, Firefox and WebKit.
